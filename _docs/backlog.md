# Household Chores — MVP Backlog

## Задачи

### 1. Создание household chore со сроком и список активных задач

Создать модель `Chore` с `title`, обязательным `due_date` и необязательным
`due_time`. Добавить миграцию, форму создания, URL и страницу списка активных
задач. Форма должна отклонять пустой title, отсутствие due date и due date в
прошлом; после сохранения задача должна появляться в списке с title и сроком.

Проверка: тесты модели/формы для допустимых и недопустимых данных и
интеграционный тест успешного POST с отображением созданной задачи в списке.

**Результат:** первый полезный инкремент — член семьи может зафиксировать
домашнюю задачу с обязательным дедлайном и увидеть её среди активных.

### 2. Назначение одного ответственного члена семьи

Добавить в `Chore` связь с одним существующим членом семьи и миграцию. Дать
возможность назначить или изменить ответственного для существующей chore;
показывать его в списке. Форма должна сохранять только одного ответственного.

Проверка: тесты выбора существующего члена семьи, сохранения ровно одного
ответственного и отображения назначенного человека на chore.

### 3. Завершение chore и её видимость

Добавить состояние `Open`/`Completed` и действие «mark completed». Любой
пользователь MVP-интерфейса может перевести chore в `Completed`; назначенный
член семьи остаётся только информацией об ответственности. После этого chore
должна исчезать из списка активных задач и оставаться видимой как завершённая
вместе со статусом, ответственным и сроком.

Проверка: тесты успешного перехода `Open` → `Completed`, исчезновения из
активного списка и видимости завершённой chore вместе с её статусом.

### 4. Финальная MVP-регрессия и документация запуска

Дополнить README командами для миграций, запуска сервера и тестов. Выполнить
весь Django test suite и `manage.py check`; вручную проверить сценарий:
создать chore со сроком, назначить одного члена семьи и отметить её завершённой.

Проверка: успешные `manage.py check` и `manage.py test`; документированные
команды воспроизводимы в чистом окружении `uv`.
